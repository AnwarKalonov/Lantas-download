Versions · macOS

Every build, and the day it shipped

Releases are published to GitHub and this page reads them from there, so what you see is what exists — newest at the top. Pick the build for your Mac, or keep the version you already have: Lantas never replaces itself in the background. When a newer version is out, the app says so and waits for you.

Earlier versions

all releases on GitHub

Builds are ad-hoc signed, so macOS asks you to approve Lantas once in System Settings → Privacy & Security → Open Anyway. After that it opens normally. Version numbers are the release tags on GitHub — v1.0.5 is the release named 1.0.5 here.

Which build

Apple silicon covers every M-series Mac. Not sure: the Apple menu → About This Mac says which chip you have.

dmg to install · app.zip if you would rather unzip it yourself
macOS 11 or newer

How updating works

There is no background updater and no account. The app checks the same release feed this page uses and shows a notice when a newer version exists; you download it and replace the copy in Applications yourself.

nothing installs itself · nothing is sent about you

Staying on a version

Every release keeps its files, so an older build stays downloadable. If a newer version ever misbehaves, open its predecessor from this page and drag it back into Applications.
